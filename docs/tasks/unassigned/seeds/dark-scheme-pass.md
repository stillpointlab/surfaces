# A dark scheme pass

The local host follows the system's colour scheme, and Context Manager has no dark scheme, so
the local host is the first place the formats and apps are seen dark. Stage 4 found the code
editor's highlighting dark on dark (the code format's theme; stage 4 follow-ups, host-page).
Stage 5's specs check each app's shell by hand in a dark scheme as it is built.

A pass would open every format's preview and editor, and both apps, in a dark scheme and fix
what does not read: the code theme first, then whatever the shared tokens do not reach.
