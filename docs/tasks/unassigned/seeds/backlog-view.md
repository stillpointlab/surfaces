- customized for backlog grooming
- vertical list from current stage, current phase, next phase, etc., next stage, next stage, then
  backlog

  - items in stages/phases aren't ordered
- each card displayed as a row with just title: description on one line
  - click to expand to full size - entire digital good editor displayed
  - rest of rows scroll off screen on expand but pane still is scrollable
    - I can still scroll up and down in the list to see other task/brief/investigation rows and
      headers for other stages/phases
  - only one editor open at a time. If user selects another the old one closes and the new one opens
